## Ground rules for the bot

- Always work on a branch, always open a PR. Never push to `main` directly.
- Never open, read, or print the contents of any credential or secret file (`serviceAccountKey.json`, `.env`, etc.).
- If a task needs a decision only the project owner can make - a design choice, missing content only they have, a product tradeoff - stop and describe the blocker in the PR or an issue instead of guessing.
- Keep changes scoped to the one item being worked. Don't bundle unrelated fixes into the same PR.
- Only public-domain Bible translations get synced/stored in full (Douay-Rheims is confirmed public domain - see `syncFullBible`'s `BIBLE_SOURCES` comments). The project owner has copies of the Ignatius Bible (RSV, 2nd Catholic Edition) and the NRSV on their own machine for personal reference, but holds no license for either, and isn't pursuing one. Do not add a sync source, parser, or any bulk storage of either translation's text - both are under active copyright held by their publishers (Ignatius Press / National Council of Churches).
- Hymn audio synthesis stays instrumental for now. Do not start on sung lyrics/vocal synthesis without the project owner explicitly asking first - tune/instrumental accuracy is the current priority, and they're actively getting outside musical advice on it.
